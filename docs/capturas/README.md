# Capturas de pantalla

Las capturas deben tomarse desde un emulador o dispositivo real con el backend activo (no se pueden generar sin ejecutar la app). Lista sugerida para el informe, con el nombre de archivo esperado:

**Trabajador:** `01_bienvenida.png`, `02_registro.png`, `03_onboarding.png`, `04_inicio.png`, `05_registro_estres.png`, `06_test.png`, `07_resultado_test.png`, `08_respiracion.png`, `09_pausas.png`, `10_carga_laboral.png`, `11_desafios.png`, `12_biblioteca.png`, `13_psicologos.png`, `14_reserva_horarios.png`, `15_mis_citas.png`, `16_compartir_informe.png`, `17_zenbot_crisis.png`, `18_perfil.png`, `19_modo_oscuro.png`.

**Psicólogo:** `20_estado_en_revision.png`, `21_rechazado_reenvio.png`, `22_bienvenida_verificado.png`, `23_inicio_psicologo.png`, `24_pacientes.png`, `25_agenda.png`, `26_disponibilidad.png`, `27_informes.png`, `28_perfil_profesional.png`.

**Admin:** `29_admin_usa_web.png`.

Nota: las pantallas de informes y fichas de pacientes usan `FLAG_SECURE`, por lo que el sistema bloquea las capturas. Para documentarlas, usa datos de prueba y comenta temporalmente `SecureScreen()` en una build local.
